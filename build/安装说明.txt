安装说明 / Install Guide
========================

⚠️ 首次打开如果被系统拦截（未签名版本），请用下面任意一种方法：

方法一（推荐，右键打开）：
  1. 把 DeepSeek Desktop 拖进"应用程序"
  2. 在"应用程序"里右键点击它 → 选"打开"
  3. 弹窗再点一次"打开"

方法二（终端命令，最彻底）：
  打开"终端"（Terminal），粘贴这一行回车：
  xattr -cr "/Applications/DeepSeek Desktop.app"

之后就能正常双击打开了。第一次启动会自动解压内置组件（约 1 分钟）。

需要填 DeepSeek API key：打开应用 → 顶部"⚙️设置/控制中心" → API 凭据。

----------------------------------------

⚠️ If macOS blocks the app on first launch (unsigned build), use either:

Option 1 (recommended, right-click):
  1. Drag DeepSeek Desktop into Applications
  2. In Applications, RIGHT-CLICK it → "Open" → "Open" again

Option 2 (Terminal, most reliable):
  Open Terminal and paste:
  xattr -cr "/Applications/DeepSeek Desktop.app"

Then double-click normally. First launch extracts the bundled runtime (~1 min).

Enter your DeepSeek API key via the top bar → ⚙️ Settings → API credentials.
